# Словарик

Слово, перевод и пример из твоего кода. Добавляем по несколько слов за урок.

- **Атрибут** (`attribute`, «признак») — пометка внутри открывающего тега вида `имя="значение"`. Пример: `src="images/1.jpg"`, `alt="вид спереди"`, `class="card"`, `data-photos="..."`. Как запомнить: элемент — человек, атрибуты — его паспортные данные.
- **`data-` атрибут** — атрибут, который придумал ты сам. Браузер его не читает, а JS читает через `card.dataset`. Пример: `data-photos`.
- **Массив** (`array`) — список значений в квадратных скобках, у каждого значения есть номер. Пример: `photos` равно `['images/1.jpg', 'images/2.jpg']`.
- **Индекс** (`index`, «номер места») — номер элемента в массиве, счёт идёт с нуля. Пример: `photos[0]` — первое фото, `photos[4]` — пятое.
- **`split`** («разделить») — метод, который режет строку на куски по разделителю и даёт массив. Пример: `card.dataset.photos.split(` `)` режет по пробелу.
- **`let`** («пусть») — переменная, значение которой можно менять. Пример: `let index = 0;`.
- **`const`** (от «константа») — переменная, значение которой после создания менять нельзя. Пример: `const modal = ...`.
- **`undefined`** («не определено») — значение, когда JS не нашёл то, что просили. Пример: `photos[2]` у массива из одного элемента. Красной ошибки при этом нет.
- **`F5`** — обновить страницу в браузере. Если код правильный, а результат старый, начни с этого.
- **Функция** (`function`) — именованный кусок кода, который можно запускать по имени. Объявить (описать) и вызвать (запустить) — разные вещи: запускает запись со скобками `showPhoto();`. Пример: `function showPhoto() { ... }`.
- **`length`** («длина») — сколько элементов в массиве. Пример: `photos.length` у первой карточки равно 5, а последний номер 4, то есть `photos.length - 1`.
- **`button`** («кнопка») — HTML-элемент, на который можно кликнуть. Пример: `<button id="next" class="arrow">`.
- **`target`** («цель») — элемент, по которому реально кликнули. Пример: `event.target === modal` значит «кликнули именно по фону».
- **Всплытие** (`bubbling`) — клик по вложенному элементу считается и кликом по его родителю. Из-за этого нужна проверка `event.target`.
- **Комментарий** — текст в коде, который браузер пропускает. JS: `// текст`, CSS: `/* текст */`, HTML: `<!-- текст -->`. Горячая клавиша `Ctrl+/`. Пиши зачем, а не пересказывай код.
- **Параметр и аргумент** (`parameter`, `argument`) — то, что функция принимает через круглые скобки. Параметр описывается в объявлении: `function (event)`. Аргумент передаётся в вызове: `querySelector(`#modal`)`. У `showPhoto()` скобки пустые, ей данные не нужны, но скобки всё равно обязательны.
- **`else if`** («иначе если») — следующее условие в цепочке `if`. JS проверяет условия сверху вниз и выполняет первое совпавшее. Пример: клавиши `Escape`, `ArrowRight`, `ArrowLeft`.
- **`true` и `false`** («истина», «ложь», то есть «да» и «нет») — результат сравнения или вопроса. Пример: `photos.length === 1` даёт `true` у карточки с одним фото, а `false` у остальных.
- **`contains`** («содержит») — метод `classList`, который отвечает `true` или `false`: есть ли у элемента класс. Пример: `modal.classList.contains(`open`)`.
- **`hidden`** («скрытый») — свойство элемента: `true` прячет его, `false` показывает. Пример: `prevBtn.hidden = photos.length === 1;`. Не сработает, если в CSS у элемента задан свой `display`.
- **`Home` и `End`** — названия клавиш (в `event.key`) для перехода к началу и концу. На ноутбуках часто через `Fn` + `←` и `→`.
- **Путь** (`path`) — адрес файла или папки. Слэши разделяют уровни. Пример: `images/soldaty/1.jpg` — папка `images`, в ней `soldaty`, в ней файл `1.jpg`. Папки и файлы пиши латиницей, строчными, без пробелов.
- **Цикл `for`** («для») — повторяет блок кода несколько раз. Три части в скобках: начало, условие продолжения, шаг. Пример: `for (let i = 1; i <= 5; i++) { ... }`. Когда условие даёт `false`, цикл останавливается. Подробнее разберём в сессии 2.
- **`push`** («толкнуть») — добавляет элемент в конец массива. Пример: `photos.push(...)`.
- **`Number()`** («число») — превращает текст в число. Значения из `data-` приходят текстом: `"5"`, а не 5.
- **Шаблонная строка** (`template literal`) — строка в обратных кавычках, куда через `${ }` подставляются значения. Пример: `` `${title}, фото ${index + 1}` ``.
- **`textContent`** («текстовое содержимое») — текст внутри элемента. Можно читать (`card.querySelector(`h2`).textContent`) и записывать (`caption.textContent = ...`).
- **`p`** (от `paragraph`, «абзац») — HTML-элемент для блока текста. Пример: `<p id="caption">`.
- **`position: absolute`** — вынуть элемент из обычного потока и поставить по координатам (`top`, `bottom`, `left`, `right`) относительно ближайшего родителя с `position`.
- **Серая переменная в VS Code** — подсказка, что переменная объявлена, но нигде не используется.
- **Рефакторинг** (`refactoring`) — переделка кода без изменения поведения. Пример: вынесли показ фото в `showPhoto()`.
- **Объект** (`object`) — набор пар `ключ: значение` в фигурных скобках. Значения достают по имени через точку. Пример: `{ title: `Custodes Warden`, folder: `images/warden`, count: 5 }`, `miniature.title`. Запомнить: массив по номерам, объект по именам; `[ ]` массив, `{ }` объект. Не путать со словом «архив» (zip-файл).
- **Ключ** (`key`) — имя поля в объекте. Пример: `title`, `folder`, `count`.
- **Массив объектов** — массив, элементы которого сами объекты. Пример: `miniatures`. Достать данные: `miniatures[1].title` (сначала номер, потом ключ).
- **`createElement`** («создать элемент») — создаёт пустой тег в памяти. На странице его не видно, пока не сделан `append`. Пример: `document.createElement(`article`)`. Запомнить: создать, заполнить, вставить.
- **`append`** («приложить в конец») — вкладывает элемент внутрь другого. Пример: `gallery.append(card)`, `card.append(img, heading)`. Порядок в скобках — порядок на странице.
- **`className`** («имя класса») — записывает класс элементу, как `class="..."` в HTML. Пример: `card.className = `card``.
- **`forEach`** («для каждого») — выполняет функцию для каждого элемента массива по очереди. Пример: `miniatures.forEach(function (miniature) { ... })`, где `miniature` — один объект на текущем круге.
- **`NaN`** (`Not a Number`, «не число») — результат, когда число получить нельзя. Пример: `Number(undefined)`. Условие `i <= NaN` всегда `false`, цикл не делает ни одного круга.
